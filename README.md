# Clip campaigns

Take-home: paid clipping campaigns (Next.js 15 / tRPC / Drizzle / Postgres).

- **Live:** https://take-home-fullstack-v3.vercel.app
- **Notes:** [NOTES.md](./NOTES.md)

## Quick start (local)

```bash
cp .env.example .env
docker compose up -d
pnpm install
pnpm db:migrate
pnpm db:seed
pnpm dev
```
